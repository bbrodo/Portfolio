# Portfolio

A personal portfolio for showcasing my projects and work.

The starter uses Vite with plain HTML, CSS and JavaScript. GSAP, Lenis and Three.js are available for future animation, scrolling and 3D work.

```sh
npm install
npm run dev
```

Edit `index.html` to add your name, project details and contact information. The styles live in `src/styles/index.css`, and `src/main.js` is the entry point for interactions.

Use `npm run build` to build the site and `npm run preview` to serve the build locally.
